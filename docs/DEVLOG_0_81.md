# Rolling Thunder MD — v0.81 Alpha

This update brings the ROM down to **4 MiB / 32 Mbit**, adds new portraits for
Albatross and Leila, and gives Leila's in-game sprite violet hair across all ten
stages.

Other improvements include:

- Arcade attract mode.
- Controller settings and C-button jump support.
- Correct player visibility when entering doors.
- Fixes for sound-test freezes, missing transition audio, and PAL startup.
- Game-over and restart fixes.

Tested on Genesis Plus GX and PicoDrive, including regional startup checks and
1P/2P regression tests.

Performance is still a work in progress. Busy late-game co-op scenes can slow
down, and the benchmark found small later-stage solo Leila regressions. Physical
hardware testing remains outstanding.

See the [release notes](RELEASE_0_81.md) for the ROM checksum, validation details
and known limitations.
